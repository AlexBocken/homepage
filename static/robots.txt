# ===================================================================
# AI crawlers
#
# Policy: content on this site may NOT be used as LLM training material,
# but AI-assisted *search* is welcome: bots that only build a search index
# or fetch a page live because a user asked for it may crawl the public
# content like any other search engine (they fall under "User-agent: *"
# below and inherit its Disallows).
#
# Allowed on purpose (search index / user-triggered fetch, not training):
#   OpenAI      OAI-SearchBot, ChatGPT-User
#   Anthropic   Claude-SearchBot, Claude-User
#   Google      Googlebot, Gemini/agent fetchers (Google-Extended below only
#               opts out of Gemini *training*, not Search or AI Overviews)
#   Microsoft   Bingbot (no separate training token exists; Bing honours
#               "noarchive" as the AI-training opt-out instead)
#   Apple       Applebot (Siri/Spotlight; Applebot-Extended below is training)
#   Meta        meta-externalfetcher, meta-webindexer
#   Amazon      Amzn-SearchBot, Amzn-User
#   Perplexity  PerplexityBot, Perplexity-User
#   Mistral     MistralAI-Index, MistralAI-User
#   DuckDuckGo  DuckAssistBot   You.com  YouBot   Kagi  kagi-fetcher
#
# Blocked: everything whose operator documents it as collecting content
# for model training, or which sells scraped corpora to AI companies.
# Multiple user-agents can share one rule block.
# Sources: the operators' own bot docs and github.com/ai-robots-txt.
# ===================================================================
